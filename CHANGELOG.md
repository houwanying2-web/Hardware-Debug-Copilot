# Changelog

All notable public changes to Hardware Debug Copilot are recorded here.

## v0.1.0-beta — 2026-09-17

First public beta.

### Added

- Circuit-aware diagnostics for non-inverting, inverting, and voltage-follower op-amp circuits.
- Periodic low-side N-channel MOSFET gate-drive diagnostics.
- Stable sine-wave ADC and sampling-chain diagnostics.
- Chinese and English Windows desktop GUI with persistent language selection.
- Fully local and offline waveform analysis.
- Self-contained HTML engineering reports with embedded waveform SVG.
- Optional localized Markdown report export.
- Built-in Chinese and English PDF user guides.
- Friendly localized input and analysis error messages.

### Beta limitations

- Diagnostic results are engineering-assistance suggestions, not component-failure proof.
- Some thresholds require validation with more real hardware data.
- v0.1.0 does not include schematic recognition, cloud analysis, accounts, AI chat, a component database, or automatic updates.
